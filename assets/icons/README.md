# Icons

SVG icon assets, organized by purpose. Files are added manually — this structure
exists ahead of that so new icons land in a consistent place.

- `navigation/` — sidebar / nav-item icons (e.g. home, calendar, favorites, fichas, notifications, profile).
- `actions/` — interactive/action icons (e.g. edit, delete, close, logout, search, chevrons).
- `sports/` — per-sport icons/marks, paired with the `sport-*` color tokens in `app/theme.css`.
- `status/` — state/feedback icons (e.g. verified, pending, rejected, warning, success).
- `logo/` — ScoutLink logo marks and wordmark variants.
